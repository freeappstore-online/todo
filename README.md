# Todo

A simple todo list to keep track of what needs to be done.

**Live:** https://todo.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `todo`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
